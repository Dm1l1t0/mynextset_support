# mynextset_support

Pagine pubbliche di MyNextSet (app per iPhone, iPad e Android), pubblicate con GitHub Pages su
`https://dm1l1t0.github.io/mynextset_support/`.

| Pagina | Italiano | English |
|---|---|---|
| Presentazione (URL di marketing) | `index.html` | `en/index.html` |
| Assistenza | `supporto.html` | `en/support.html` |
| Informativa sulla privacy | `privacy.html` | `en/privacy.html` |

`stile.css`, le icone e le immagini in `img/` sono comuni alle due lingue.

Gli indirizzi sono usati dalle app (Impostazioni → Assistenza) e dalle schede di App Store e Google Play:
se rinomini o sposti una pagina, aggiorna anche le app. Quando cambi l'informativa, aggiorna la data in
alto in entrambe le lingue. Dopo la pubblicazione sugli store, sostituisci i riquadri "Presto su" in
`index.html` e `en/index.html` con i link alle pagine dell'app.

Per pubblicare una modifica: `git add -A`, `git commit`, `git push`. GitHub Pages si aggiorna in un paio di minuti.
